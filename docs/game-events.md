# Game events

Every observer event the game sends itself, generated by `tools/events_doc.py` from the game
definition. Scripts follow any of them with `boz.game_events.on(name, fn)`: the handler gets
`{name, id, subject, sender, a, b}`; `a` and `b` mean what the notes say (pointers to the
game's structs where noted). Returning true from a handler stops the event.
